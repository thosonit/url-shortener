# Feature Index

## MVP features

- Create a short link from a long URL
- Redirect short code to the original URL
- Google sign-in for saved link management
- Custom aliases / vanity URLs
- Link expiration
- Click analytics
- URL validation (http/https only, reject self-referential links)
- Link history for authenticated users
- Anonymous TTL with 30-day auto-expiry
- Click count tracking
- Link claim on sign-in via anonymous session
- Minimal rate limiting for anonymous creation
- "Link expired" page with 410 response

## Phase 2 / advanced features

- CMS admin dashboard
- Role-based permissions and admin RBAC
- Custom alias moderation and reports
- Blocklist management
- Audit logging for mutating actions
- Detailed analytics (geo, referrer, device)
- User suspension and role assignment
- Auto-reporting rules and abuse detection
