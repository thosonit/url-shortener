# F008 — Link history for authenticated users

## Purpose
Allow signed-in users to review and manage their saved links.

## Summary
- List user-owned links in the authenticated dashboard.
- Show original URLs, short codes, click counts, and status.
- Provide actions like copy and open.

## Acceptance criteria
- Authenticated users can see only their own links.
- Link metadata is displayed clearly.
- Actions work from the history view.
