# F101 — CMS admin dashboard

## Purpose
Provide admins with a centralized operational overview.

## Summary
- Show KPIs like total links, daily clicks, and open reports.
- Surface rate-limit and abuse indicators.
- Link to detailed admin pages for links, reports, blocklist, users, and audits.

## Acceptance criteria
- Admins can see system health metrics at a glance.
- Dashboard links to operational workflows.
- Admin metrics update consistently.
