# F108 — Auto-reporting rules and abuse detection

## Purpose
Automatically generate reports for suspicious or abusive behavior.

## Summary
- Generate reports when a blocked domain is used.
- Flag IPs that exceed link-creation thresholds.
- Surface automated report alerts in the admin queue.

## Acceptance criteria
- System-generated reports appear in the report queue.
- Admins can resolve auto-generated reports like user reports.
- Abuse detection rules are configurable.
