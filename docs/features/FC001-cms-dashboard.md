# FC001 — Admin dashboard

## Purpose
Give admins a centralized operational overview at a glance.

## Summary
- Surface system KPIs and abuse indicators.
- Link out to the operational workflows.

## Sub-features
| ID | Sub-feature | Detail |
|----|-------------|--------|
| FC001.1 | KPIs | Total links, links/clicks today, open reports, rate-limited IPs. |
| FC001.2 | Growth charts | Link and click growth over time. |

## Acceptance criteria
- Admins see system-health metrics at a glance (FC001.1).
- Trends are visualized over time (FC001.2).
- Dashboard links to link management, reports, blocklist, users, and audit.
