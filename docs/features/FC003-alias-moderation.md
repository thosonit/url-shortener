# F103 — Custom alias moderation and reports

## Purpose
Handle abusive or inappropriate aliases through reactive moderation.

## Summary
- Allow custom aliases to go active immediately.
- Accept user reports for bad aliases.
- Present reported aliases in an admin queue.
- Allow admins to disable or keep aliases with a reason.

## Acceptance criteria
- Reported aliases are visible to admins.
- Admins can resolve reports with actions and notes.
- Disabled aliases stop resolving.
