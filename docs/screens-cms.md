# CMS Screens

## Screen index

- Dashboard
- Links
- Reports
- Blocklist
- Users
- Audit log

## Dashboard

Purpose: provide a high-level operational view.

Content:
- Total links and total clicks
- Links/clicks today
- Open reports count
- Rate-limited IP summary
- Growth charts (links and clicks)

## Links

Purpose: inspect and manage all links in the system.

Content:
- Search and filter by code, URL, owner, status
- Actions: disable/enable, force-expire, view click history
- Link metadata including alias and owner

## Reports

Purpose: triage user reports and automated policy alerts.

Content:
- Report queue with reporter, reason, and affected link
- Actions: keep, disable, dismiss
- Resolution note and reason capture

## Blocklist

Purpose: maintain domains that cannot be shortened or redirected.

Content:
- List of banned domains
- Add / edit / remove blocked domains
- Reason and audit history for each entry

## Users

Purpose: manage user accounts and roles.

Content:
- List of users and their status
- Suspend / unsuspend actions
- Assign roles (admin, super-admin)
- View user-owned links

## Audit log

Purpose: track every mutating admin action.

Content:
- Immutable event list
- Actor, action, target, timestamp
- Metadata details for each change
